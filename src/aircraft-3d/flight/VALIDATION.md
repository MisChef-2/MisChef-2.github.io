# v6 공항 보완 자료 — 2026-11-22

기존 OSM 3개 공항 외 나머지 63곳을 3개 지역 에이전트로 조사했습니다. 46곳은 FlightGear 참고 연결 경로, 11곳은 공식 원문 기반 주기점 959개를 추가했습니다. 일본 4곳은 제3자 AIP 미러입니다. 베이징·광저우·선전·자카르타·괌·함부르크 핀켄베르더 6곳은 연결/자료 부족으로 이동 보류입니다. 공식 주기점만 있는 11곳도 자동 이동은 보류합니다.

사용: 조종석 비행 → 지상 이동 → 게이트 ↔ 게이트 · 보완 자료. 공항별 출처, 도면 날짜, 통과 활주로는 ground-reference-report.html에서 확인합니다. 참조 경로는 현행 공항 운영, 항공기별 통과 폭, 실제 관제/푸시백 절차를 인증하지 않습니다.

검증: 46곳의 출발·도착 경로와 비행 여정 연결 검사 통과. 방향성 간선, 임의 연결 방지, 활주로/건물 침범 차단, 기존 3곳 16방향 회귀 검사 통과. 11곳 959점의 좌표·식별자·유도로 미생성 검사 통과. 브라우저 HND→LAX 및 LAX→HND 준비 성공, HND→LAX 도착 유도로 단계 표시 확인. GMP 좌표 전용 경로 거부 확인. 기존 ICN265→15R / NRT16R→22 재확인. 라이브 추적 단위 회귀 통과. 새 공항 전체에 대한 육안 주행 검증은 미완료입니다.
