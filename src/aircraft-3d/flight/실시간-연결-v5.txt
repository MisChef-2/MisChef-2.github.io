조종석 비행 v5 — 2026-11-22

사용법
항공편-시점-미리보기.cmd 실행 → 항공기 탭 → 항공편 선택 → 조종석 보기.
실제 운항 데이터는 사이트의 기존 API 연결 기능과 유효한 FlyItalyADSB 키가 필요합니다.
키가 없으면 '예시 항공편 조종석 보기'가 제공되며 실제 운항으로 표시하지 않습니다.
원래 항공편 사이트 창을 열어 두세요. 조종석 페이지 주소만 복사하면 연결되지 않습니다.

완료
- 21개 기종 패밀리의 대표 조종석으로 항공편 진입.
- 지도용 추측 위치를 쓰지 않고 원시 관측 위치와 관측시각 보존.
- 선택한 실기체의 위치를 기존 키로 15초마다 추가 조회. 키는 새 창에 전달하지 않음.
- 10초 보간 버퍼. 관측 사이만 보간하고 마지막 좌표 밖으로 추측 비행하지 않음.
- 30초 이상 갱신이 없으면 중단 표시. 실제 데이터 오류를 예시 데이터로 바꾸지 않음.
- 관측 위치의 지형, 공항 주변 장면, UTC 태양/별 환경과 Open-Meteo 모델 기상 연결.
- 지연된 관측시각이 기상 조회 범위보다 앞설 때 화면이 멈추던 오류 수정.

검증
- 21기종 모델을 브라우저에서 각각 로딩하고 42개 기장/부기장 시점 전환, 순항 진입 확인.
- 21개 기종 캡처: review-v5. 실제 조종석과 완전 동일하다는 인증은 아님.
- 예시 JJA1502의 사이트 버튼→737 조종석 연결, 위치 갱신, 실제 Open-Meteo 응답 확인.
- 원래 창 종료 후 32초 시점 '갱신 중단·마지막 관측 위치에서 정지' 확인, 앱 JS 오류 없음.
- 390×844 iframe 실제 viewport에서 가로 넘침 없음, 준비 후 설정 접힘, 순항 이동 및 설정 복귀 확인.
  물리적 휴대전화 실기 검사는 아님. 브라우저 viewport override가 적용되지 않아 iframe으로 검증함.
- 기존 지상 이동/경로/지형 회귀 검사와 메시지 출처·단위·시각·보간·오류 처리 검사 통과.
- D: 로컬 설치 및 현재 build.sh 재빌드 완료. hub-app.js와 공용 3D 모델은 수정하지 않음.

남은 범위
- 실운항 API 키를 사용한 실제 기체 수신의 종단간 검증은 미실시. 예시 항공편과 모의 응답으로 기능 검증.
- 66공항 중 게이트 원자료는 기존3개(인천·나리타·제주). 추가 조회는 HTTP406/429·시간초과로 실패.
- 기종별 날개 통과 폭, 주기장 허용 기종, 견인·관제 절차는 검증되지 않았음.
- 조종석은 대표 기종 모델. 실기체 등록번호별 세부형식/객실/계기/자세를 직접 수신하지 않음.
- 지상 항공편에서 유효한 고도·진행 방향이 없으면 조종석 연결 보류.
- 기내 카메라 영상이 아님. 수신 고도와 실제 해발고도의 차이 및 지표 기상 한계가 있음.
- 공개 배포 미실시.
